# cleanup 0.1.7-rc.1

This preview adds photo and video sorting, last-run dates, measured app sizes and a Folders page.

Download **Cleanup.exe** for the portable app, or **cleanup-0.1.7-windows-x64-setup.exe**
for a per-user installation. Windows 11 x64 is required. Both downloads include their runtimes.

## Changes

- Photos and Videos under Organize sort the photos or videos directly in a folder into year and month folders by the date they were taken or recorded. Dates come from camera metadata in JPEG, HEIC, AVIF, PNG, WebP, TIFF and camera raw files, and from MP4, MOV, M4V and 3GP movie headers. A file without one uses the date it last changed, and the preview says which date was used. Other files stay where they are, every move is previewed, and History can undo it.
- Applications has a Recently running sort. Open programs say Running, and the rest show when they last ran, from Windows history, Store app usage, Steam and, after a Windows prompt, the administrator activity log. That log is reused for 12 hours.
- Programs whose installer never recorded a size show the measured size of their own folder, and the total at the top includes it.
- More installed programs are listed, including system components and installs without an uninstall command. Remove stays off when there is no uninstaller. Windows updates, patches and built-in Windows pieces stay off the list.
- Folders shows which folders use the most space, with search, sorting, a scan log and an option to keep scanning while other pages are open. Windows system folders are left out.
- Patch notes, above Settings, lists these changes in the app.
- Run as administrator, at the top right, can restart cleanup elevated. Always run as administrator is off until you turn it on, asks Windows on every launch, and can be turned off in Settings. [ADR 0004](https://github.com/wiredincorp/cleanup/blob/main/docs/adr/0004-opt-in-elevation.md) records the decision and its limits.
- Last-run matching handles trailing slashes, `uninstall.exe` registrations, versioned Store folders, shortcuts and generic helper names. Folder sizes do not follow links or total shared locations.
- If Windows cannot start an elevated copy, cleanup keeps running as a normal account instead of closing.

## Installation and data

Keep **CleanupData** beside the portable EXE to carry settings and history between PCs.
If that directory is read-only, the app uses the current user's profile. Setup preserves user data on uninstall.
The settings and history formats are unchanged from 0.1.6 apart from one new optional setting.
This release still uses native ABI 3; keep its frontend and native library together.

## Preview status

These downloads are **unsigned**. Windows may show an unknown-publisher warning, and managed-device policies or Smart App Control can block unsigned applications. Some official uninstallers may request Windows approval, and so does the optional administrator mode on every launch.

The release workflow runs native and managed checks, verifies per-user install and uninstall, and checks portable startup with Windows animations off and on. It also exercises photo sorting and undo on a disposable fixture. SHA-256 checksums, build provenance and dependency notices accompany the downloads.
