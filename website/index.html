04 / FAQ

Questions.

01What does cleanup do?

It removes apps with their official uninstallers, checks for leftovers, and sorts folders after you see a preview. History lets you undo eligible file moves.

02Will it touch files without asking?

No. Every folder move needs a preview and your OK. Subfolders, protected paths, links, hidden and system files, partial downloads, and cloud-only files stay put. Nothing is silently overwritten.

03Can I undo everything?

File moves, yes, if the file is unchanged and its original path is available. App uninstalls can’t be undone.

04Is it a registry cleaner or PC booster?

No. No speed claims, no debloating, no background service. It removes apps, reviews leftovers, and sorts folders.

05How does Portable work?

Run Cleanup.exe from any folder. Settings and history are saved beside it when the folder is writable, and in your Windows profile when it isn’t. The first launch unpacks support files to a temporary cache.

06What do I need?

Windows 11 on x64. Everything else is included.

07Is it open source?

Yes. It’s MIT licensed.
