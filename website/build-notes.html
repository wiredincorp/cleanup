Install for Windows

Run the setup file to install cleanup for your Windows account. It adds a Start menu entry and an uninstaller.

Install for Windows

Portable for USB

Copy Cleanup.exe to a USB drive and run it on a Windows 11 x64 PC. When the drive is writable, CleanupData beside Cleanup.exe stores settings and history. On a read-only drive, cleanup uses your Windows account profile. The first launch extracts Windows support files to a temporary cache.
